# 前端改版说明

> 阶段历史记录：下文描述该阶段的方案、测试数与未完成项，不等同于当前状态。当前入口、权限和持久分析实现请参阅 [项目首页](../README.md) 与 [最新验收说明](system-acceptance.md)。

本次改版只调整 Vue 前端，继续使用现有 FastAPI 接口。

## 设计方向

品牌工作名为「巡境」，采用深绿导航、暖灰背景、白色内容区和低饱和青绿色。
参考：
- Formant Operations：https://www.formant.ai/operations
- InOrbit Control 文档：https://www.inorbit.ai/docs

借鉴运维工作台的信息组织：地图、设备状态、任务和异常分层；未复制品牌、素材或页面。

## 页面

- 运行总览：实际设备和任务统计、工厂地图、轨迹、图层开关、缩放、设备状态、最近任务、助手。
- 巡检任务：最近 200 条记录，本地搜索和状态筛选，详情跳转。
- 检测记录：最近 500 条结果的图片卡片、检测状态、异常说明、任务筛选和 CSV 导出。
- 任务详情：沿用点位与事件审计，统一视觉。
- 助手：保留 SSE 工具过程与确认卡片，增加常用问题入口。

## 数据边界

统计为接口返回的有限记录，不是全量统计。地图设备轮廓为布局示意，墙体与门来自现有地图资产。
设备在线与否以接口遥测为准；接口不可用时显示连接失败。没有写入演示业务数据。
兼容 current_task 为任务号或点位对象；对象不含任务号时按机器人查找非终态任务用于概览，不能据此解决后端任务互斥问题。

## 验证

- npm run build 通过；Element Plus 仍有大包体积提示。

- 390px 宽度检查未出现横向页面溢出。
- 未进行真实 ROS/MQTT/模型联调：检查时后端 8000 端口未运行。
