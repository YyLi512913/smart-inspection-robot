# 登录与操作权限

本版为单工作空间接入账号、数据库会话和角色权限，不设置默认账号或默认密码。首次打开本机 /login，创建管理员后即可进入，后续由管理员创建其他账号。历史任务、告警与图片保留，旧操作记录不会被改写成新账号。

## 权限

| 功能 | 查看人员 | 巡检操作员 | 管理员 |
| --- | --- | --- | --- |
| 查看设备、遥测、任务、图片、告警 | 是 | 是 | 是 |
| 创建巡检、取消、阻塞决策、聊天执行 | 否 | 是 | 是 |
| 确认告警、误报、处理记录、设备复检 | 否 | 是 | 是 |
| 修改本人密码、退出登录 | 是 | 是 | 是 |
| 创建账号、角色调整、停用、重置密码、账号审计 | 否 | 否 | 是 |

前端隐藏无权操作，后端同时保护全部 /api/ 接口（首次初始化、登录和初始化状态除外），包括图片访问。healthz 保持公开用于探活。首次初始化仅允许回环连接，并以数据库互斥行保证只能创建一次。

操作人由后端登录身份决定。任务创建人、取消与决策记录、告警处理人、复检创建人都会忽略客户端伪造的 created_by / actor。聊天会话绑定账号，其他账号无法接管会话；每次 Agent 工具执行会重新校验会话与角色，避免退出或降权后继续执行写操作。同一会话串行执行。

## 会话和密码

密码至少 12 个字符，以随机盐 scrypt 哈希保存。会话令牌随机生成，数据库仅保存令牌的 SHA-256 摘要，有效期 8 小时。浏览器通过 HttpOnly、SameSite=Strict Cookie 持有令牌，CSRF 值仅在前端内存中使用，不存 localStorage。

写请求必须携带当前会话的 X-CSRF-Token；有 Origin 的请求还要匹配允许来源。首次初始化和登录没有已登录会话，但同样检查 Origin。退出、停用、角色调整、重置密码或本人改密都会撤销对应会话。最后一个启用的管理员不能被停用或降级。

登录失败使用一致错误，按来源地址与用户名组合限制 5 分钟内的尝试次数。账号创建、权限变化、密码操作和登录事件有独立审计记录，密码和原始会话令牌不进入审计。

## 配置和部署边界

- AUTH_ALLOWED_ORIGINS：允许的浏览器来源，逗号分隔；默认允许本机 localhost / 127.0.0.1 的 5173、8000 端口。
- AUTH_COOKIE_SECURE：本地 HTTP 默认 false；部署到 HTTPS 时设为 true。
- AUTH_ALLOW_SETUP：默认 true，用于本机首次创建管理员；完成初始化后可显式设为 false。

当前启动方式仍绑定 127.0.0.1。首次初始化应在本机完成后再开放外部访问；反向代理必须正确限制初始化入口和配置允许来源。账号体系不是多租户隔离或企业 SSO，也不保护独立的 MQTT broker；跨机器部署需要同时配置传输安全和 broker 认证。

## 测试和升级

迁移 006_auth.sql 增量建表。系统后台 MQTT、状态机、分析队列不依赖浏览器登录，登录保护不会中断已在执行的机器人任务。

94 项后端测试通过，其中 HTTP 权限测试运行真实本地 ASGI 服务和独立 MySQL 数据库，覆盖匿名访问、只读写入、越权管理、CSRF、跨来源、会话撤销、登录限制、最后管理员、操作人伪造、复检身份和聊天会话隔离。前端构建通过，仍有原有的大包提示。

浏览器隔离验收完成首次创建管理员 → 创建查看人员 → 退出 → 查看人员登录 → 查看三台设备，确认写按钮和账号管理不可见。验收账号只存在于独立测试数据库，不会添加到你的工作空间。
